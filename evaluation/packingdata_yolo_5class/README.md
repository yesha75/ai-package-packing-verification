# Five-class packing-scene YOLO dataset

Filtered from Zenodo packingdata to the five annotated object classes can, cup, plate, bowl, apple. Original train/test split is preserved; only images containing at least one selected class are included. COCO xywh boxes were converted to normalized YOLO xywh. This is a separate packing-scene experiment and does not replace the app demo_kit classes (bottle, cup, book, cell phone). Source: Zenodo DOI 10.5281/zenodo.7904630.
