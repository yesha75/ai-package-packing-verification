# COCO sample images and labels

25 reproducibly sampled COCO 2017 validation images containing at least one of the project classes (bottle, cup, cell phone, book). Images and YOLO-format labels are copied unchanged from the public COCO validation set. These are ordinary COCO scenes, not package-packing scenes, so they are useful for reproducibility/detector debugging only and must not be reported as package-verification evaluation.

Original source dataset: https://cocodataset.org/#download . Cite Lin et al., Microsoft COCO: Common Objects in Context (ECCV 2014). COCO class IDs: bottle=39, cup=41, cell phone=67, book=73. Labels include all COCO classes.
